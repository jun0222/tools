# 高速回転学習タイマー

高速学習法のための専用タイマーアプリです。「意味がわからなくても止まらない」「拾えるものだけ拾って次へ」という学習スタイルをサポートします。

## 特徴

### 🔄 高速回転学習に最適化
- 10秒〜60秒の短時間タイマー
- 自動的に次の周回へ移行
- 現在の周回数を常に表示

### 📊 学習統計
- 本日の総周回数を自動記録
- LocalStorageで統計を保存
- 日付が変わると自動リセット

### 📱 スマホファースト設計
- タッチ操作に最適化された大きなボタン
- 縦画面での快適な操作性
- レスポンシブデザイン

### 🎵 フィードバック機能
- 周回完了時のサウンド通知
- バイブレーション機能（スマホ）
- 視覚的なフラッシュエフェクト

### ⚡ 便利機能
- プリセットタイマー（10秒/20秒/30秒/60秒）
- カスタム時間設定（5〜600秒）
- スクリーンロック防止機能
- 一時停止・再開機能

## 使い方

1. **タイマー設定**
   - プリセットボタンで素早く設定
   - または、カスタム入力で好きな秒数を指定

2. **学習開始**
   - 「スタート」ボタンをタップ
   - タイマーが0になると自動的に次の周回へ

3. **統計確認**
   - 画面上部で現在の周回数と本日の総周回数を確認
   - 集中して何周回できたかを可視化

4. **リセット**
   - 「リセット」ボタンで現在のセッションをリセット
   - 本日の統計は下部ボタンで個別にリセット可能

## 推奨される使い方

### 📚 教科書・問題集の場合
- **1周目**: 10〜20秒 - とにかく速く目を通す
- **2〜3周目**: 20〜30秒 - 拾えるものだけ拾う
- **4周目以降**: 30〜60秒 - 理解を深める

### 📝 暗記物の場合
- 10秒タイマーで超高速回転
- 1日に10周以上を目標に

### 💡 コツ
- 完璧を目指さず、とにかく回転数を増やす
- わからない部分は飛ばしてOK
- 繰り返すうちに自然に理解が深まる

## 技術仕様

- フレームワーク不要のバニラJavaScript
- TailwindCSSでスタイリング
- LocalStorageで統計管理
- Wake Lock APIでスクリーンロック防止
- Web Audio APIでサウンド生成
- Vibration APIでハプティクス対応
