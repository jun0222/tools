# インターバル音声ファイル生成ツール

指定したインターバルと繰り返し回数で、数字を読み上げる音声ファイル（MP3）を生成します。

## セットアップ

### 1. 必要なソフトウェア
- Python 3.7以上
- ffmpeg（pydubで必要）

### 2. ffmpegのインストール

macOSの場合：
```bash
brew install ffmpeg
```

### 3. Pythonライブラリのインストール

```bash
pip install -r requirements.txt
```

または個別にインストール：
```bash
pip install gtts pydub
```

## 使い方

```bash
python generate_interval_audio.py
```

実行すると対話形式で以下を入力します：
1. インターバル秒数（例: 30）
2. 繰り返し回数（例: 10）
3. 出力ファイル名（Enter でデフォルト）

## 実行例

```
インターバル秒数を入力してください (例: 30): 30
繰り返し回数を入力してください (例: 10): 10

音声ファイル生成開始...
  インターバル: 30秒
  繰り返し回数: 10回
```

## 仕組み

- 各インターバル後に数字（1、2、3...）を日本語で読み上げます
- Google Text-to-Speech (gTTS) を使用するため、**インターネット接続が必要**です
- 生成されたMP3ファイルはスマホなどで再生して、バックグラウンドタイマーとして使用できます

## 注意事項

- インターネット接続が必要です（gTTSがGoogle APIを使用するため）
- 繰り返し回数が多いと生成に時間がかかります
- ffmpegがインストールされていない場合はエラーになります
